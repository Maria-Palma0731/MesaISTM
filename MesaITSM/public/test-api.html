Prueba de API REST - Módulo de Reportes

GET Dashboard de Reportes

/api/reports/dashboard

Obtiene estadísticas generales del sistema (tickets, usuarios, KB, servicios).

GET Reporte de Tickets

/api/reports/tickets?date_from=2025-10-01&date_to=2025-11-26

Lista de tickets con filtros de fecha, estado, prioridad, tipo y técnico.

GET Rendimiento de Técnicos

/api/reports/technicians

Métricas de productividad y eficiencia de técnicos.

GET Servicios Más Solicitados

/api/reports/services

Top 20 servicios más solicitados con tasas de resolución.

GET Reporte de Base de Conocimiento

/api/reports/knowledge-base

Estadísticas de artículos de la base de conocimiento.

GET Tendencias Temporales

/api/reports/trends

Datos de tendencias de tickets creados y resueltos por día.

GET Exportar Datos (JSON)

/api/reports/export?type=tickets&format=json

Exporta datos en formato JSON.
